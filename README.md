RADAR-4 — Momentum-weighted launch clock. A token launch radar over 178 pre-token protocols from the 2026-11-14 DeFiLlama snapshot, with the 40-protocol watchlist fully covered. Radar-2 ranks by implied value (TVL × growth × tenure × breadth); the launch clock re-weights it by category momentum — a categoryMult from each category's mean 7-day change, clamped to ±20% — and scores every protocol 0–100 on age plus growth to read off a launch window (soon under 90 days, mid 90–180 days, late over 180 days). The dashboard is a light "paper terminal": a category-momentum heatmap, a top-10 "most likely to launch" spotlight, the biggest rank movers between radar-2 and radar-4, two worked examples recomputed live from their own rows, and a sortable, filterable board whose detail view recomputes every number from the row's own figures and adds a seven-step farm plan. Everything is computed from the snapshot's numbers only — no protocol is hardcoded by name.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input <path-to-snapshot.json>
```
